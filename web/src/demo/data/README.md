# Synthetic presentation fixtures

These seven JSON files are hand-authored examples for the existing UI tests and optional `VITE_DEMO_DATA=1` mode. They are not copied from source CSVs, a local database, a captured authenticated response or the scenario answer keys. Names and IDs match existing presentation tests; the counts and verdicts are synthetic.

Use the real backend and its replay/pack tests to assess routing, eligibility, forecasts and trap behavior. These files establish that the web can compile and display its response shapes in a clean checkout; they do not validate the algorithm.
